The chosen gamepad layout

Positions, not letters: on a Nintendo-style pad the bottom button uses and the right one goes back. PlayStation: Cross uses, Circle goes back, Triangle opens the build list, L1 runs, Options pauses.

If the pad disconnects, the game pauses wherever a pause exists (see unplug-b.html); where there is none yet, he simply stops. Keyboard, mouse and any connected pad all work at the same time. Variants that were considered and not chosen sit beside this page.
