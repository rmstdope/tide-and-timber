Nintendo-style pads — option B: By letter

The button printed A always uses and the one printed B always goes back. On a Switch pad A is on the right, so it matches what Nintendo players expect from Switch games. Cost: muscle memory flips for anyone moving between an Xbox and a Switch pad. Xbox and PlayStation pads are the same under both options.
